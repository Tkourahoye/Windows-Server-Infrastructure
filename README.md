# Infrastructure Windows Server — Projet d'entreprise simulée

Déploiement complet d'une infrastructure réseau d'entreprise sous Windows 
Server, couvrant l'annuaire, les services réseau, la sécurité, l'accès 
distant et la haute disponibilité.

## 🏗️ Composants déployés

| Module | Description | Statut |
|---|---|---|
| **AD DS** | Annuaire Active Directory, gestion des utilisateurs/groupes/OU | ✅ |
| **DNS** | Résolution de noms, zones primaires/secondaires | ✅ |
| **DHCP** | Attribution dynamique d'adresses, étendues, réservations | ✅ |
| **Partage de fichiers** | Permissions NTFS/partage, dossiers de groupe | ✅ |
| **GPO** | Politiques de groupe (sécurité, déploiement, restrictions) | ✅ |
| **Accès distant / VPN** | RRAS, VPN site-à-site ou client | ✅ |
| **WDS** | Déploiement d'images Windows par le réseau | ✅ |
| **Redondance (HA)** | NLB, Failover Clustering, stockage iSCSI | ✅ |
| **Exchange Server 2019** | Messagerie d'entreprise | 🔄 En cours |

## 🧰 Environnement
`Windows Server 2019` `VMware` `Active Directory` `DNS/DHCP` `RRAS` 
`WDS` `NLB` `Failover Clustering` `Exchange Server`
